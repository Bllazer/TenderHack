# TenderHack — frontend

React, TypeScript, Vite и Oxlint. Пошаговый подбор КТРУ в оформлении Портала поставщиков. Источник результатов — реальный POST `/api/v1/analyses`, локальное демо стаканов и генерация DEMO-кодов удалены. Backend не ограничен конкретным товаром.

Из `frontend/`:

```sh
pnpm install --frozen-lockfile
pnpm dev       # http://localhost:5173
pnpm build
pnpm lint
```

`src/App.tsx` хранит полное состояние формы, ответы, категорию и правки между шагами. `src/api.ts` отправляет его целиком при каждом анализе. Правка требует повторной проверки; успешный код берётся только из selected_ktru_code сервера. AbortController и номер запроса защищают от устаревших ответов. Показываются загрузка, ошибки, дополнительные фрагменты, вопросы и проверка кандидатов. Оформление и локальные Open Sans/OFL сохранены.

Vite проксирует `/api/*` на `http://127.0.0.1:8000` без удаления префикса. Адрес меняется через API_PROXY_TARGET в `.env.local`; секреты не помещайте в VITE-переменные. [Полный API](../backend/docs/API.md).

Compose из корня запускает API и nginx/frontend на http://localhost:8080 с тем же `/api`. Пока очищенного каталога нет, сценарий показывает needs_data и сохраняет форму; завершение подбора недоступно.

## Браузерная проверка

Нужен установленный backend с dev-зависимостями; тесты запускают отдельный API на 18001 с **синтетической фикстурой**, Vite на 5174 и Chromium. Это не режим рабочего приложения.

```sh
pnpm exec playwright install chromium
# PowerShell из frontend/, если backend использует локальное venv:
$env:BACKEND_TEST_PYTHON=(Resolve-Path ../backend/.venv/Scripts/python.exe).Path
pnpm test:e2e
```

Проверяются реальный HTTP-сценарий категория → обязательное поле → правка → смена категории → подтверждение, защита от устаревшего ответа и отображение HTTP-ошибки. TEST-коды используются исключительно тестами.
