# TenderHack — frontend

Минимальная основа: React, TypeScript, Vite и Oxlint. Начальный экран — приветствие ТендерХак.

## Команды

Из папки `frontend/`:

```sh
pnpm install --frozen-lockfile
pnpm dev       # разработка: http://localhost:5173
pnpm build     # проверка TypeScript и сборка в dist/
pnpm lint      # проверка кода
pnpm preview   # просмотр готовой сборки
```

Зависимости зафиксированы в `pnpm-lock.yaml`. При добавлении пакетов коммитьте и обновлённый lock-файл.

## Структура

- `src/App.tsx` — корневой экран.
- `src/App.css` — стили приветственного экрана.
- `src/index.css` — общие стили.
- `src/main.tsx` — точка входа.
- `public/` — статические файлы.

Компоненты и экраны добавляйте по мере появления функционала.

## FastAPI

В режиме разработки Vite перенаправляет запросы `/api/*` на `http://127.0.0.1:8000`, сохраняя путь. Например, `fetch('/api/health')` обращается к `http://127.0.0.1:8000/api/health`. Маршруты согласуйте с командой бэкенда.

Чтобы изменить адрес, скопируйте `.env.example` в `.env.local`, задайте `API_PROXY_TARGET` и перезапустите Vite. Секреты в переменные с префиксом `VITE_` не помещайте: они доступны браузеру.

Прокси Vite действует только при разработке. При развёртывании настройте прокси `/api` на FastAPI на сервере либо отдельный адрес API и CORS на бэкенде.
