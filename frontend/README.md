# TenderHack — frontend

React, TypeScript, Vite и Oxlint. Пошаговый интерактивный макет подбора КТРУ в стиле UI kit Портала поставщиков.

## Команды

Из папки `frontend/`:

```sh
pnpm install --frozen-lockfile
pnpm dev       # разработка: http://localhost:5173
pnpm build     # проверка TypeScript и сборка в dist/
pnpm lint      # проверка кода
pnpm preview   # просмотр готовой сборки
```

Зависимости зафиксированы в `pnpm-lock.yaml`. При добавлении пакетов коммитьте и обновлённый lock-файл.

## Структура

- `src/App.tsx` — корневой экран.
- `src/App.css` — стили модуля подбора.
- `src/index.css` — общие стили.
- `src/main.tsx` — точка входа.
- `public/` — статические файлы.

Компоненты и экраны добавляйте по мере появления функционала.

## FastAPI

В режиме разработки Vite перенаправляет запросы `/api/*` на `http://127.0.0.1:8000`, сохраняя путь. Например, `fetch('/api/health')` обращается к `http://127.0.0.1:8000/api/health`. Прикладные запросы: `/api/v1/*`. Полный контракт: [`backend/docs/API.md`](../backend/docs/API.md).

Чтобы изменить адрес, скопируйте `.env.example` в `.env.local`, задайте `API_PROXY_TARGET` и перезапустите Vite. Секреты в переменные с префиксом `VITE_` не помещайте: они доступны браузеру.

Прокси Vite действует только при разработке. При развёртывании настройте прокси `/api` на FastAPI на сервере либо отдельный адрес API и CORS на бэкенде.

## Демонстрационный режим

Макет работает без бэкенда. Доступен сценарий со стаканом: полное описание сразу ведёт к результату, неполное — к уточнению материала, объёма и назначения. Результат можно подтвердить или исправить; возврат сохраняет предыдущие ответы.

Разбор текста — ограниченный локальный пример, не полноценное распознавание естественного языка. Коды DEMO-CUP-* условные и не относятся к официальному КТРУ. Для рабочего подбора требуется подключить API и реальные данные справочника.

Open Sans хранится в public/fonts вместе с лицензией OFL; внешняя загрузка шрифтов не требуется.
