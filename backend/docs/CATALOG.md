# Контракт проверенной поставки

Это описание потребителя данных, а не новый XML/XLSX-конвертер. Команда должна согласовать формат очищенной поставки с этими структурами; backend не подключает непроверенный tenderhack_dataset.zip. Перед публикацией поставки нужна сверка значений, знаков, OR, единиц, кодов и метаданных с источником.

Формальная JSON-схема доступна через `Catalog.model_json_schema()` в `app/catalog.py`. Дополнительные поля запрещены, неизвестные возможности нельзя молча игнорировать. Рабочий каталог имеет synthetic=false; synthetic=true разрешён только тестам.

## Подключённая clean (5)

`app/clean_supply.py` читает **полный** `ktru_actual_all.jsonl.gz`, `okei_units.json`, `example_unit_strings.json`, `source_issues.json`, `validation_report.json`, `category_rules.json` один раз при старте. Это адаптер готовых JSON, не XML-конвертер. Тематические подкаталоги не ограничивают область. Исходная папка `ktru_clean/` остаётся внешней поставкой; Compose монтирует её read-only. Версия `clean5-<hash>` зависит от SHA всех шести потребляемых файлов. Для переноса приложения поставку нужно предоставить отдельно.

Проверены количества по отчёту: 60 087 позиций, 5 897 шаблонов, 54 190 конечных, 234 363 характеристики, 45 537 родительских ссылок, 7 позиций с source_issues, 7 830 конечных позиций без характеристик. Ссылки, циклы и идентификаторы валидируются общим `Catalog`. 3 545 значений no_new_features остаются null. Категории поставки эвристические, поэтому адаптер не создаёт из них Category и не выставляет link_verified/coverage_verified. Рабочее покрытие подтверждённых типов — 0 до поставки карты типов и индексов ML-командой.

Позиция сохраняет version/source_status/parent_code/is_template/no_new_features/reason/source_issues/resolve_blocked/reasons; полная исходная запись (метаданные, даты, классификаторы, parent_position) остаётся в raw_json. source_path содержит SHA, номер строки, код и версию. Характеристика сохраняет source_type/kind/choice_type/required и свой raw_json. allowed содержит отдельные элементы OR с исходными value_code/raw_unit/okei_code/source и строгими границами. Интервалы с равными границами допустимы только при обеих включённых границах. Ошибочный элемент не превращается в число: вся характеристика становится unsupported, исходная конструкция остаётся в raw_json.

kind=3 сохраняется, но текущая проверка множественного выбора не поддерживается: unknown, без ложного конфликта нескольких допустимых значений. Неподдерживаемый type, неизвестная единица/оператор или обязательность не дают value_verified. Все семь source_issues блокируют завершение (три относятся к шаблонам); resolve_blocked=true также блокирует, false не доказывает совместимость. Позиции без характеристик остаются unknown. Шаблон запрещён для confirmed_ktru_code.

126 единиц с 130 spellings и usage_total сохраняются вместе с 63 aliases, включая исходные context/global_safe. Суммы usage и ссылки aliases проверяются. Контекстные мин/мин-1/с принимаются только при единственном совпадающем коде ОКЕИ допустимых элементов характеристики. Угловые минуты/секунды не подменяются временем. Известные преобразования ограничены явной таблицей OKEI_SUPPORTED и существующим app/units.py; неизвестные размерности сохраняются и блокируют проверку. Числу без единицы единица каталога не присваивается.

Если ML-команда предоставит согласованный нормализованный snapshot и manifest, они имеют приоритет и проверяются существующим load_snapshot, включая контрольные суммы. При наличии исходной clean (5) catalog_version обязана совпадать с версией поставки. Подготовка артефактов — offline; инструкции и границы ответственности в [ML_INTEGRATION.md](ML_INTEGRATION.md).

## catalog.json (format_version=1)

- catalog_version: версия поставки; source_description и validation_report: происхождение и отчёт проверки.
- categories: id/name/search_text/position_codes/link_verified/coverage_verified/evidence. search_text содержит проверенное описание типа, а не правила выбора по числам; с ревью `e382611` в него входит ещё часть «Назначение: …» — формулировки назначения и синонимы класса товара из `app/synonyms.py` (кодов КТРУ и конкретных семейств там нет). Подтверждённая область должна перечислять все конечные позиции напрямую либо через семейства. link_verified и coverage_verified требуют evidence, но их истинность должна быть проверена командой по источнику.
- positions: code/name/parent_code/is_template/status/okpd2/no_new_features/no_new_features_evidence/source_path/raw_json/properties/quarantined. status: actual/terminated/unknown. is_template и no_new_features — true/false/null, неизвестное не равно false. Исходные коды и метаданные сохраняются. parent_code указывает на явный шаблон. Циклы, неизвестные ссылки, дубликаты и quarantined=true отклоняются.
- properties: id/name/aliases/source/evidence/subject/value_type/required/verified/allowed/semantic_key. Идентификатор контекстный; одно имя не доказывает тождество. source: ktru/portal/spgz; subject: product/packaging; value_type: text/number/boolean/unsupported. required — true/false/null. Проверенные алиасы и semantic_key требуют содержательной сверки; verified требует evidence. Пустой allowed, unsupported и неизвестная обязательность не доказывают значения.
- allowed: kind=enum/number/interval; value, lower, upper, lower_inclusive, upper_inclusive, unit, raw_unit, okei_code, value_code, source. **Единица и value_code принадлежат каждому элементу.** Несколько элементов — OR. Границы десятичные строки, минус сохраняется. Интервал может иметь одну открытую сторону. Непустой source обязателен. Нижняя граница больше верхней и нечисловые/бесконечные значения отклоняются.

Числовые элементы объединяются только после проверки совместимых известных размерностей. `%` не Ом, об/мин не минуты; единица правила не подтверждает единицу числа пользователя. Разные/неизвестные единицы дают unknown. Пустые правила и непроверенные позиции не допускают resolved. codes_disjoint_on_values не поддерживается и не используется.

Интервал с равными границами допустим только с двумя включёнными концами (`[a;a]`). `(a;a)`, `[a;a)` и `(a;a]` — пустые ограничения, загрузчик их отклоняет. Они не превращаются в допустимое число и не используются для объединения OR. Если дефект присутствует в источнике поставки, адаптер должен сохранять его происхождение и блокировать проверку позиции, а не исправлять границы догадкой.

Если исходная конструкция не представима достоверно, используйте value_type=unsupported/verified=false и сохраните исходник; не превращайте её в придуманное ограничение. Весь карантин исключается из рабочей поставки до индексации. Неизвестные статусы/шаблоны делают покрытие неполным.

## Индексы и модель

`python -m app.prepare index <catalog-dir> --model-dir <model-dir>` создаёт offline:

- vectors.npy: нормализованная float-матрица N×384, порядок categories;
- tokens.json: лемматизированные BM25 документы в том же порядке;
- manifest.json: catalog_version, analyzer_version, model_id, model_revision (40-символьный SHA), sha256 для catalog.json/vectors.npy/tokens.json.

Модель — `intfloat/multilingual-e5-small`, локальные config/tokenizer/model.safetensors плюс model.meta.json с revision и SHA файлов. Downloader запускается отдельно до API. Запросы не скачивают веса. Смена каталога требует новой индексации и перезапуска процесса; несовпадение SHA/версий/размерности блокирует readiness. Snapshot загружается один раз, матрица и структуры доступны только для чтения. При отсутствии поставки рабочая версия — awaiting-validated-supply, покрытие 0.
