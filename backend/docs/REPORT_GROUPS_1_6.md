## Что исправлено, с запросами до/после

**Группа 1 — приоритет явно названного свойства**

```
Было:  «Халат; Наличие карманов да, нарукавники нет»
       → Наличие карманов = «да, нарукавники нет»   (значение затянуло соседнюю пару)
Стало: → Наличие карманов = «да»; «, нарукавники нет» остаётся в unparsed
```
Твои два примера (`… Да | Наличие нарукавников Нет` и `В составе комплекта Нет | Наличие карманов Да`)
на текущей ветке дают по одному факту на названное свойство, неизвестная пара уходит в `unparsed`
(проверено через HTTP). Ограничение: если имя свойства вне области, а значение совпадает со
значением единственного свойства области, значение всё ещё может достаться ему — помечено `xfail`
с причиной в `tests/test_explicit_pairs.py`.

**Группа 3 — CSV не меняет смысл данных**

```

Стало: разделитель не найден → одноколоночный файл → «Дрель мощность 0,65 кВт», note в ответе

Стало: → «Дрель; Мощность: 650 Вт; Напряжение: 220 В»
```

## Оставшиеся ограничения

1. **Значение пары с неизвестным именем** может достаться единственному свойству области с тем же
   значением (группа 1, помечено `xfail`) — нужна согласованная правка механизма безымянных значений.
2. **Порог масштаба** `2×/10×` в проверке неправдоподобных значений — калибровка по данным каталога;
   при смене поставки её надо перемерять (рецепт в [VALUE_LIMITS.md](VALUE_LIMITS.md)).
3. **nginx/Docker не запускались**: лимит `client_max_body_size 4m` изменён в конфиге, но проверен
   только через эмуляцию nginx (статику и прокси `/api` отдаёт локальный скрипт). Реальный
   nginx-путь и `docker compose` остаются непроверенными.
4. **Браузерные (Playwright) тесты не запускались**: браузеры не установлены, установка требует сети.
   Фронтенд проверен сборкой (`tsc -b && vite build` без ошибок) и наличием новых элементов в бандле.
5. **E5 проверен** (прогон с `RUN_E5_TESTS=1`), эмбеддинги не пересобирались: поисковые документы
   не менялись.
6. **Два падения `batch_check.py`** (устаревшая проверка `engine_version` в самом тесте и
   `needs_data` на «Киянке») воспроизводятся на чистом `main` — это состояние обновления.
7. **Критерий жюри** (уникальный код при незаполненных обязательных полях) не внедрён — см. документ.
