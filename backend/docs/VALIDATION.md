Для воспроизведения контейнерных тестов после Compose из корня:

```sh
docker compose cp backend/tests api:/srv/tests
docker compose exec -T api uv sync --frozen --extra search --extra dev
docker compose exec -T -e RUN_E5_TESTS=1 api python -m pytest -q
```

Dev-зависимости устанавливаются только в проверяемый контейнер, не в production Dockerfile. Модель должна быть подготовлена до этой команды. E2E использует отдельный тестовый API и синтетический encoder; настоящий E5 и вся оркестрация дополнительно проверяются Python-тестом.

Источник ответа теперь сохраняется для правки, но не используется как доказательство в другой категории; регрессия проверяется API и браузером. Варианты вопроса собираются из всех оставшихся позиций в одном контексте. Неподдерживаемое необязательное правило тоже не считается проверенным.
