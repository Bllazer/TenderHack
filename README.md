# TenderHack

React/Vite и stateless Python/FastAPI: описание → извлечение → поиск категории → уточнение → проверка конечных позиций → ручное подтверждение кода. Данные формы живут в браузере; каждый запрос передаёт полное текущее состояние. Базы данных и серверного хранения анализов нет.

```sh
# Из корня репозитория
docker compose up --build -d
```

Frontend: http://localhost:8080, API: http://localhost:8000/api/docs. Nginx и Vite сохраняют `/api`.

Очищенная поставка получена. Рабочий каталог в репозитории остаётся пустым намеренно: подготовленные артефакты (каталог, векторы, токены) собираются локально в игнорируемую папку `backend/resources/catalog-build/` и не коммитятся. Без сборки API отвечает `needs_data`, readiness — HTTP 503.

## ⚠️ Требует правок перед финальной сдачей

1. **`OKEI_SUPPORTED` — три неверных кода.** `050` помечен как `см²`, хотя это квадратный миллиметр (см² — `051`); `271` помечен как `Ом`, хотя Ом — это `274`, а сам `274` в таблице отсутствует. Отсутствующий код даёт честный `unsupported` и блокирует позицию, а **неверный проходит как проверенный**: 112 конечных позиций принимают неправильную единицу молча и могут дойти до `resolved` с неверным сравнением. После правки поставку и индексы нужно пересобрать.
2. **Порог значимости в `Search.find`.** Поиск всегда возвращает 5 кандидатов, поэтому на товар, которого нет в каталоге, показывает случайные совпадения с уверенным видом. Решение об изменении контракта не принято.
