# TenderHack

Репозиторий команды хакатона 9–11 октября 2026.

- `frontend/` — React + TypeScript + Vite.
- Бэкенд на FastAPI команда добавит в `backend/`.

## Запуск фронтенда

Нужен Node.js 22.12+ (или более новый поддерживаемый LTS) и pnpm.

```sh
npm install --global pnpm@11
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://localhost:5173.

Подробнее о структуре, проверках и подключении API — в [frontend/README.md](frontend/README.md).
